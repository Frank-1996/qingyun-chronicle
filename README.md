## 已有玩法

- 从学前、幼儿园、小学、初中、高中，到本科、硕士、博士的学生经历。毕业后自主选择继续升学或任职，不同学历有不同晋升速度。
- 虚构省市县镇、学校、研究院和任职机构，人生档案记录毕业、入职、升迁、退休。
- 背景音乐随年龄和人生阶段变化，升学／升迁使用独立音效；金手指按少年、成年、晚年分三个曲库，使用不限次。前景音乐串行，背景自动降低音量。
- 五维数值可突破100，全部破百获得仙值，可抹去一次失误的晋升影响。
- 体力低于25时可能患病，低体力且患病时有因病早逝风险，休养可以康复；中老年体力逐日衰减。
- 分层退休机制，退休后停止晋升，仍可继续生活与年度事件。
- 兼容第一版存档、本地自动保存与导入导出；源码和规则保留扩展空间。

**音乐说明：未内置当前热门短剧原声，也未完成热门原曲的机器情绪分析。** 默认是原创替代配乐；设置中可以按年龄和人工正负情绪标签配置HTTPS音频，或导入仅在当前会话播放的本地原声。来源状态始终在界面中明确显示。

## 本地运行与测试

需要 Node.js 18+，不需要安装依赖：

```sh
node server.mjs
# 打开 http://127.0.0.1:4173
node --test tests/*.test.mjs
```

也可使用 `npm start`、`npm test`。`dist/`为静态站点目录；请通过HTTP服务运行，不要直接以file://打开。GitHub Actions在main更新时运行测试并发布Pages。

## 游戏规则

初始五维总点数100，每项5–60；成长无100上限。每日一项活动同时促进五维，体力、实践和品德影响成长效率。体是物质基础，劳是根本实践途径，德统领方向，智提供能力，美丰富精神。

日／周／月／年观察与履历收益倍率为1／0.85／0.68／0.5；属性、衰老与疾病按天结算，快进在每年生日决策和升学选择前暂停。游戏一年固定365天，月30天。

高中及以下／本科／硕士／博士的任职成长倍率为1／1.12／1.24／1.36。健康存活、年年正确的基础目标为 `min(floor(寿命×0.8),72)` 岁，学历加速可更早达到国家主席。失误、疾病与退休可能改变结局。

领导职务层级决定退休年龄：基层60岁、厅局65岁、省部70岁、国家80岁。退休后保留最高职务与级别，停止升迁。

现实职级名称参考 [公务员职务与职级并行规定](https://www.gov.cn/xinwen/2019-03/27/content_5377422.htm)：展示12职级、10层领导职务与27至1的数字级别。晋升节奏、教育录用、退休年龄与对应映射均为虚构规则，不作为现实制度说明。
