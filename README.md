# 青云纪 · The Qingyun Chronicle

在虚构国家「澄川」，从出生到国家主席的浏览器人生模拟游戏。v0.1.0，可完整游玩一生。

## 运行

需要 Node.js 18+，无需安装任何依赖：

```sh
npm start
# 浏览器访问 http://127.0.0.1:4173
npm test
```

`dist/` 是可直接部署的静态站点目录，也可部署至 GitHub Pages。请使用 HTTP 服务运行，不要以 file:// 打开。

## 玩法

- 自定义或随机角色，初始五维总和固定100，每项5至60。寿命可设70至110岁，默认90岁。
- 德统领方向，智提供能力，体是物质基础，美丰富精神，劳是根本实践途径。每日活动同时影响五维，身体、实践与品德影响成长效率，五维共同影响履历积累。
- 以365日作为游戏年；周7日、月30日、年365日，快进在年度节点暂停。每次推进沿用所选活动，每天结算属性。
- 日、周、月、年观察与履历收益倍率：1 / 0.85 / 0.68 / 0.5。逐日投入获得更多履历与详尽年报，可减轻错误决策的延误。成长属性不因快进缩水。
- 每年一次关键选择。22岁入职，全选正确于 `floor(寿命 × 0.8)` 岁到达国家主席。每次错误造成进度延误，观察积累可部分抵消。
- 金手指「闻弦知意」为每个选项播放正向或悲伤音乐，正确答案位置随角色种子和年龄变化。当前使用 Web Audio 程序配乐（含随机转调），不是流行短剧原曲。
- 自动本地保存，支持 JSON 导出／导入、重开、寿终总结。单机无账户与联网排行榜。

## 制度与游戏规则

参考 [公务员职务与职级并行规定](https://www.gov.cn/xinwen/2019-03/27/content_5377422.htm)，呈现二级科员至一级巡视员的12个综合管理类职级；领导职务为乡科副职至国家正职的10层，国家主席是本游戏国家正职终点。数字级别另以27至1展示。

现实中职级、职务与级别有不同含义和对应范围，本游戏不把12职级宣称为领导职务。本版按叙事进度映射三套显示，任期、退休、职数、选任制度与对应区间尚未完整模拟，不作为现实制度说明。

## 架构与迭代

`dist/engine.js`：独立纯状态引擎、角色、数值、职级、事件与存档校验。

`dist/app.js`：界面与本地持久化，所有用户输入输出经过文本转义。

`dist/audio.js`：音乐金手指，`MUSIC.positive` / `MUSIC.negative` 可配置自有或获授权音频URL。不要直接加入未授权短剧原声。

`tests/engine.test.mjs`：无第三方依赖的核心机制测试。

见 [迭代路线](docs/ROADMAP.md)。现阶段为开放数值的单机原型；JSON可编辑，不能用于公平竞技或真实玩家筛选。未来在线评估应采用服务端权威状态。
