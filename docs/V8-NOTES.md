# 卷八 · 天命与史鉴（v0.8.0）

## 姓名与开局

姓名候选共85,240个，以朴实、常见的姓与名组合为主，提高常见姓氏权重。提供朴实日常、当代、传统文雅、两字、三字、复姓6种风格，每组12个候选，可刷新或手填。名字的性别风格只影响命名，不影响角色数值；字数模式不自动混入复姓。既有角色、家属姓名不强制重写，新增人物使用新库。

8种天命：平常人家、书香门第、百工传家、仁厚家风、筋骨强健、艺事熏陶、四海为家、大器晚成。初始五维总点数仍为100，效果仅影响后续成长或跨图成本。

## 逆天改命

修仙第10境“飞升”及之后可以消耗命元更换天命。修行篇史鉴作答正确获得1命元，突破获得2命元；初次消耗8，以后每次增加4。不能在待答节点、寿元耗尽后或天命未改变时扣款；不重掷已得属性，不复活，不改写凡间档案。

## 寿元与时间尺度

凡间延寿规则仍为1仙值兑换1岁、最高150岁。修行篇使用独立寿元上限，总年龄为凡间年龄加道历年数。每次突破提升到该境界的寿元上限，不重复刷取增长；寿元耗尽停止诸天旅程，可导出档案或开启新人生。

| 境界例子 | 寿元上限 | 关键问道周期 |
| --- | ---: | ---: |
| 启灵 | 180岁 | 1年 |
| 结丹 | 1,000岁 | 10年 |
| 飞升 | 10,000岁 | 100年 |
| 候补神使 | 20,000岁 | 200年 |
| 国域主神 | 320,000岁 | 3,200年 |
| 宇宙之主 | 150,000,000岁 | 1,500,000年 |
| 多元秩序共议者 | 5,000,000,000岁 | 50,000,000年 |

关键节点间隔为当前境界基础寿元的约1%，按整年向下取整且至少1年。推进选项保留日、周、月、年，并按境界开放十年、百年、千年等跨度和直达本周期。快进会停在问道或寿元边界，不能跳题；保持细粒度观察仍有较高修为收益。此为架空数值，不是现实寿命或科学事实。

旧v0.7修行存档原本无寿元限制，迁移时保留已过道历，给予不低于当前总年龄加30个本境界周期的缓冲寿元，避免更新即死亡；原有待答节点继续可答。家族与凡间任职仍保留入道快照。

## 历史题库

本版用32个有公开出处的史实案例生成512道16个人生阶段/职务场景题，替换原先活动中的128题；旧题源仍保留以兼容历史档案。修行、神职与诸天历练也改为从这32例抽取史鉴情境，32例用完前不重复；不是512个独立史实，也不把同一案例在不同尺度的改编重复算作独立手写故事。

案例包括都江堰、青蒿素研究、大宪章、张骞出使、玄奘传译、毕昇活字、柏林空运、古巴导弹危机、气象窗口、环境协定、土壤保护、航海钟、航天安全事故、哈勃修复和跨团队单位错误等。来源来自UNESCO、国家档案馆、NASA、诺贝尔奖官网、气象机构、博物馆等。原始出处、简短史实与原创情境/判分解释分开存放，作答后有来源链接。

题设给出一个优先目标，选项比较策略与代价，不宣称历史只有唯一正确答案。幼儿题改为照护者代选的安全互动，学生是讨论与研究，基层官员是简报与建议，不让儿童或科员直接扮演国家决策者。公共卫生案例只讨论历史决策方法，不作为现实医疗建议。

## 地图配乐

保留原有3首署名开放音乐。出访其他国家、修仙、修神、单宇宙、多元宇宙使用原创程序配乐：分层旋律、持续和声、循环和声进行，按国家地理、星球、宇宙与篇章调整调式、音域、节奏和主题。切换大地图即同步，不需付费服务或API key。界面明确标记原创连续配乐；不冒充热门短剧原声。关闭音乐、前景压低背景、后台暂停、触屏解锁逻辑保留。
