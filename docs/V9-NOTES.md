# 卷九 · 游戏账户与云存档（v0.9.0）

正式入口：https://qingyunlife.cn/ 。页面顶部新增“账号 / 云存档”，匿名仍可使用本机存档游玩。

## 账户功能

- 注册、登录、退出、修改昵称、修改密码、退出所有设备。
- 用户名2—24个汉字、字母、数字或下划线，规范化后不区分英文字母大小写。用户名为固定登录标识，昵称可修改。
- 密码12—128个字符，支持长句；独立随机盐和scrypt摘要（N=32768,r=8,p=3），不保存明文密码。
- 注册时给出一次性显示的恢复码；忘记密码可凭用户名和恢复码重置，旧恢复码失效。可用当前密码重新生成恢复码。未接邮件/短信找回，同时丢失密码和恢复码无法自助恢复。
- Cookie登录7天，Secure/HttpOnly/SameSite=Strict；数据库只保存会话token摘要。密码变更及找回会撤销旧会话。
- 游戏账户与私人阅读、素材、短剧访问密码完全独立，不提供公开管理员或账号列表接口。

## 云存档

每个账户3槽、每槽最近3个上传版本，单份存档最多1.5MB。上传、载入和历史回退有明确确认；登录不自动覆盖本机或云端。

先上传当前进度或载入一个槽，再主动开启自动同步。开启后在本机保存后延迟合并上传、最长约每15秒一次；离开页面前最后几秒的变化可能只保存在本机，状态会显示“等待同步”，可手动上传确认。新建人生、手动导入、重新登录、网络错误或版本冲突会暂停自动同步。

多设备并发采用版本号比较；旧设备不静默覆盖新版本。冲突后重新查看云端，可以载入新进度，或选择空槽保存本机角色；主动上传会再次显示覆盖确认。不同网址各自登录，但同一账户访问相同后台存档。GitHub Pages静态备用入口不提供同源后端，云账户请使用正式域名或原Vercel入口。

云端保存的是单机存档，不是服务端权威角色或防作弊排行榜。上传前客户端用现有迁移校验，服务器限制结构、体积和用户隔离，不声称杜绝修改游戏数值。

## 架构与运维

程序 /opt/qingyun-accounts，独立数据 /var/lib/qingyun-accounts/accounts.sqlite3；独立账号qingyunplayer，仅监听127.0.0.1:8791。Caddy只将read.qingyunlife.cn/api/player/*转发到游戏后端；其余三个私人入口仍走原认证网关。只转发游戏Cookie，避免将私人阅读Cookie交给游戏服务。未新开公网端口，未改DNS。

EdgeOne Pages用functions/api/player/[[path]].js同源代理；Vercel用现有配置中的外部rewrite代理。所有账户响应private/no-store，禁止缓存带登录信息的内容，不能跳转到私人阅读页。

注册/登录/找回限频；敏感修改要求来源白名单、JSON自定义请求头与会话CSRF；请求大小和分块读取均有上限，运行资源受systemd限制。scrypt参数参考OWASP Password Storage Cheat Sheet：https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html 。

数据库上限512MiB；低于200MiB剩余磁盘空间暂停保存；每天北京时间约03:35备份，保留最近3个私有快照。账号库与备份目录0700、文件0600，不进入Git仓库或静态发布目录。上限含数据库，不把备份算作异地备份；如增长需另行评估空间与套餐。

现有服务器和免费托管继续使用，没有开通新付费套餐；平台函数等免费额度按当前套餐限制执行。前端Git更新自动发布；后端代码更新需执行经过测试的服务器安装流程，不自动下载远程代码执行。

管理员只在服务器控制台检查记录，不从公开网页查看密码：

    runuser -u qingyunplayer -- python3 /opt/qingyun-accounts/accounts.py --stats
    systemctl status qingyun-accounts.service qingyun-accounts-backup.timer

如需审查用户名、昵称、注册和最近登录记录，可由服务器管理员使用只读SQLite查询；不向任何人返回原始密码、摘要、恢复码摘要或会话摘要。

## 验证

72项游戏/前端/代理测试通过，12项Python后端测试本地和服务器通过。覆盖用户隔离、密码/恢复码/会话撤销、CSRF与来源拒绝、Cookie属性、分块代理请求、并发版本冲突、三版本保留、失败不冒充同步、旧游戏功能回归。

浏览器用独立本地测试账户验证登录、三槽读取、载入确认、另槽上传和自动同步；未代用户创建正式账户或设置真实密码。实体手机及微信实机验证边界另见发布记录。
