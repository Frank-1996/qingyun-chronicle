# 卷七 · 百国问道，诸天共生（v0.7.0）

本版把素材库的原创草案写入可玩的后期成长链。生产网址沿用 https://qingyunlife.cn/ ，GitHub main 更新触发原有 EdgeOne / Vercel / Pages 发布。

## 已开放

- 100个国家：10种政体×10种地理产业，独立名称、人口、任用约束、灾害和政策线索。澄川保留15亿人口。18岁任职后可出访，每岁一次外交历练。现阶段属于外交与治理框架；各国尚没有100套独立的求学、任职和家庭模拟。
- 修仙10境：启灵、养气、筑基、凝元、结丹、化婴、炼神、合道、渡劫、飞升。
- 修神9阶：候补神使至至高神议席；20种可选神职，职责包括山岳、水利、文教、医药、司法、记忆与界门等。
- 12颗具有法则和危机差异的星球，封神后开放航路。
- 单宇宙4阶：宇宙法则执掌者、万域协调者、宇宙秩序守护者、宇宙之主。最高神阶仍属于单一宇宙。
- 多元4阶与9宇宙：成为宇宙之主并完成考核后开放界门；最终可达诸界共议结局，之后仍能巡游。

## 规则

五维均超过100、持有至少1仙值，且年满60岁或成为国家主席，可以在没有待处理选择时启灵。入道消耗1仙值，封存凡间年龄、官职及家族，后期另按道历结算。入道不复活已死亡角色，也不改变凡间150岁寿命兑换上限；建议入道前导出人生存档。

道历提供日、周、月、年跨度。五维按实际日数成长，修为观察倍率依次1、0.85、0.68、0.5，每周年暂停作答。12种原创困境根据国家、星球、宇宙和资源条件组合改写；不是数百条独立手写剧情。答案轮换，资源条件改变最佳策略。

突破考察修为、功德、实践、五维最低/最高比至少25%、心劫不超过60；高阶要求踏访3或6颗星球，终局要求5个宇宙。失败扣部分修为并增加心劫，可继续修身与履职，不锁死成长。星球与宇宙穿行消耗20修为、增加5心劫，不能跳过年度抉择。

## 素材与扩展

采用 qingyun-materials/designs.py 中的原创国家组合、等级和神职，保留SHA-256与审核日期。可复现快照位于 tools/material-drafts.py，通过 tools/build-worlds.py 生成 dist/world-data.js。原始素材库、采集计划、5GB空间限制与私人文章均未改动。没有把私人采集正文发布到游戏中。

《抱朴子》《山海经》《搜神记》《周礼》仅作为素材库研究方向；本版数值、机制与事件为架空原创，不声称来自古籍原有等级或科学事实。

## 验证与边界

54项测试通过，含旧存档、原有教育/晋升/家庭/音频/移动端回归，以及完整27境界通关模拟、解锁限制、错误修复、存档校验。新增内容仍为浏览器单机，无云存档与在线排名。后期采用独立道历与组合事件框架，未来可继续添加独立国别故事、宗门、神器、星域与宇宙专属任务。
