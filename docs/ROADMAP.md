# 迭代路线

## 已完成 v0.2
- 学前至博士的可选教育路线与学历晋升倍率。
- 按学段、任职层级、退休状态匹配的16类年度事件池。
- 省市县镇、学校与任职地区，人物终身档案。
- 五维破百、仙值、疾病、早逝、衰老、分层退休。
- 分年龄背景配乐、三年龄金手指曲库与独立里程碑音效。
- v1存档迁移与本地音频／HTTPS音源配置。

## v0.3 内容与音乐
- 接入来源与使用范围明确的短剧原声，记录热度证据、情绪分类和有效期；不将程序配乐标记成热门原声。
- 扩充40个首批事件，为每个学年和任职岗位添加多条非重复题目，增加前序选择的后果链。
- 给学校增加专业、课程、升学考试、成绩与不同校园路线。
- 调整退休、教育、疾病和仙值的数值曲线；增加可导出的平衡模拟报告。
- 提供可配置的数据文件、内容校验器和事件作者工具。

## v0.4 治理与长期游玩
- 更完整的独立职级／领导职务／数字级别映射，任期、岗位与任职资格。
- 居民信任、经济、生态、公共服务和多种结局，避免仅凭单一晋升进度。
- 更多可扩展金手指能力、多存档槽、成就与可检索档案。
- 可选云同步与登录；服务端权威状态和防篡改后再考虑排行榜与玩家评估。

## 目前边界
一年365天、月30天。疾病概率、教育录用、退休和晋升均为虚构数值；当前没有现实公务员制度的完整模拟。金手指音源按人工情绪标签配置，没有自动情绪识别；未内置热门短剧原声。页面只显示最近120条行动日志，年度历史与里程碑保存于存档。字体失败时使用系统字体。纯浏览器单机数据可编辑。
