# 后续迭代

## v0.2 内容与成长
- 从当前10个主题模板扩展分年龄、分地区、分任职岗位的年度事件库，加入依赖链和前序后果。
- 将活动、事件、职级映射、晋升条件移至版本化数据文件，加入内容校验。
- 婴幼儿活动改为照护情境，加入家庭、学校、考试与职业准备阶段。
- 将五维的积累与失衡引入多分支后果；保留年年正确于寿命80%到达终点的保底路线。

## v0.3 任职与治理
- 加入真实对应区间的职级／职务／数字级别模型，独立晋升记录、任期、岗位与履职项目。
- 引入居民信任、经济、生态、公共服务，避免单一数值决定一切。
- 添加更多金手指，使用统一能力接口及冷却／消耗规则。
- 音频库按情绪标记、授权来源和可用性校验接入；当前BGM合成可作为断网回退。

## v0.4 长期游玩
- 多存档槽、成就、不同结局与可检索人生档案。
- 事件作者工具、平衡配置和旧存档迁移器。
- 可选云同步与登录；服务端结算和防篡改后再增加排行榜及玩家评估。

## 已知边界
每年固定365天，月为30天。事件目前循环抽取有限模板；12职级和10层领导职务使用简化叙事进度。无社会关系、现实任职制度及多人玩法。当前UI展示最近120条行动记录，保留所有年度历史于存档中。字体可从Google Fonts加载，失败则使用系统字体。
