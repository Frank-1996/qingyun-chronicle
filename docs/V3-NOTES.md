# v0.3.0 · 人生有伴，青云有声

- 学年级别明确显示。每年升年级、学段毕业、入学与晋升产生包含姓名、学校／职务和前后变化的结构化喜报。
- 喜报使用系统中文语音与专门的里程碑音乐；重大变化附雷声与闪电。逐条排队，避免叠音，支持跳过。系统减少动态效果时关闭闪电。
- 学历成长倍率从主界面与升学选择界面移除，仅在玩法与设定说明。
- 创建角色支持男女与三款外观底色；内置SVG头像随婴幼儿、少年、青年、中年、老年变化，包含发色、皱纹等。男女使用同一套数值规则。
- 成年后每年随机婚姻、家庭事件和子女出生，配偶职业、性格和家庭协调情况提供有限正负晋升波动。家庭有单独随机数状态，不干扰原有疾病随机序列。无未成年婚育，子女最多三人。
- 伴侣、子女与家庭状态显示在侧栏及人生档案。旧存档迁移为未婚，不伪造已发生的家庭历史。
- 全国分位基于虚构1.2亿人口、五维和任职进度推算，明确标记为模拟而非在线玩家榜。在任国家主席排名第一；退休或人生结束后显示模拟历史成就分位。
- 背景采用3首完整开放许可曲目流式播放，按场景选择。包含约2分钟的Monkeys Spinning Monkeys、3分钟的Carefree和30分钟的Fluidscape，均为Kevin MacLeod的CC BY 4.0作品。署名、来源、许可与循环／音量处理说明见游戏内音乐署名页。

## 兼容与边界

v1／v2自动迁移到v3，原存档仍保留；旧角色默认男性暖杏外观。中文播音取决于系统中文语音包与浏览器支持，失败时保留文字喜报与音乐。开放背景音乐依赖作者站点网络，加载失败时明确提示并使用程序备用音乐。完整曲目不等于无缝循环。

热门短剧原声与本版开放背景音乐是两个不同功能；本版没有将开放背景曲目冒充近期热门短剧原声。

20项机制测试覆盖学校播报、头像变化、婚育、性别规则一致性、人口排名、旧存档和前版核心玩法。
