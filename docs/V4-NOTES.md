# v0.4.0 · 家族绵延，山河有职

## 第四版变动

1. 学龄：0–2岁为学前启蒙，不设年级；3岁小班、4岁中班、5岁大班，6岁小学一年级。小学6年、初中3年、高中3年，本科和研究生沿用前版学制。幼儿园班级不再叫年级。
2. 虚构国家人口改为15亿，所有排名和分位据此计算。
3. 播报新增原创SVG场景插图，分别用于校园、毕业、任职、婚姻、新生儿、照护与晚年等情境。
4. 全家族姓名去重，子女、孙辈等使用唯一姓名。旧存档中的重复孩子姓名在迁移时去重，保留出生年与性别。
5. 22岁起可挑选伴侣：三位成年候选人展示年龄、职业、性格、健康和头像。可选择一位，也可暂不考虑；择偶时暂停推进，避免自动代替玩家结婚。
6. 父母、祖辈、配偶、子女、姻亲和后代均有独立出生年、年龄、健康、疾病、寿命与生死记录。随机患病、康复、疾病或意外死亡，终年不再随当前年份增长。
7. 内置5392个去重单位名称：16个虚构省域、128个虚构城市及所属县域，包含教育、财政、民政等工作部门和国家部委。可按关键词、层级检索并翻页；单位用于实际任职和往来。此为借鉴中国命名模式的虚构名录，不是真实机关全量数据库。
8. 科长、处长、局长、厅长、部长等具体职称独立展示，与职级／领导职务层次区分。官员往来会增加相识人物，显示姓名、职称和所属单位。
9. 支持主动离婚、随机婚姻变动、丧偶后再婚，原配偶和子女记录保留。
10. 子女22岁以后可以随机结婚，双方在22–48岁、存活并已结婚至少一年时可能生育；后续世代同样处理，能出现孙辈、重孙辈、玄孙辈等。直系后代有父母ID，校验出生间隔与婚龄。每对后代家庭最多3名子女，总亲属数量上限500，保留档案。后代带来的任职成长支持适度增加，上限8%，详细数值只留在玩法说明。
11. 重大变动雷声替换为真实录音：**Thunder — MorningGloryProductions**，来自[Freesound #195344](https://freesound.org/people/MorningGloryProductions/sounds/195344/)，[CC0](https://creativecommons.org/publicdomain/zero/1.0/)。使用公开HQ MP3预览录音，重大变动播放最多9秒、降低音量，跳过播报会停止录音。加载失败会明确提示，不用合成噪声冒充录音。网络源已验证HTTP 200、audio/mpeg。

## 兼容和边界

v1／v2／v3存档自动迁移为v4，原始浏览器数据保留。旧角色保留原伴侣和孩子，新增父母与祖辈资料按年龄生成；不会补造过去每年的家族事件。新版模拟发生在玩家仍存活的时间线，主角死亡后不能继续推进世代。亲属按年结算健康，玩家自身仍按天结算疾病。

择偶与教育毕业选择可能同时出现，必须都处理后才能继续时间。旧版21岁婚姻仅为兼容保留，新产生的婚姻统一要求双方22岁。

学校插图与其他播报插图为本项目原创矢量图。单位名称的命名结构参考[教育部机构设置](https://www.moe.gov.cn/jyb_xxgk/xxgk/neirong/gaikuang/jigou/)及地方教育、财政等政府部门常见命名，未声称照搬现实编制数量。

28项机制测试覆盖学龄边界、人口、单位去重、具体官职、择偶、离婚再婚、多代繁衍、亲属疾病死亡、姓名唯一、旧存档与前版核心机制。
