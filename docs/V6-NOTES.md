# 第六版 · 掌上人生，山河随行

版本0.6.0。生产入口由用户接入Vercel自动部署：[公开试玩](https://qingyun-chronicle.vercel.app/)。GitHub Pages保留。

## 手机布局与触屏

- 760px及以下独立手机布局：今日操作与年度抉择在前，角色五维与家庭／任职资料随后，底部四个入口可直接跳转。
- 手机按钮至少44px高，活动卡76px、时间步幅46px；使用原生click处理点按，未叠加touchstart重复执行，也不禁止缩放。
- 320px窄屏、390px竖屏、844×390横屏完成浏览器尺寸验证，无页面横向溢出。输入框字号16px，适配软键盘；长单位名称、历史题、亲属关系自动换行。
- 适配安全区与动态视口高度。手机播报、教程、音乐设置和名录弹窗可滚动，继续按钮便于点按；年度回顾与插图保留。
- PC保留三栏布局、所有养成、决策、家族、任职、音频及文件存档功能；手机底部导航在PC隐藏。删除阻塞渲染的Google Fonts远程导入，使用本地中文字体回退。

## 微信及嵌入式浏览器

- 不依赖微信登录、签名或JS-SDK即可游玩。点击启用声音，预解锁并复用音频元素；监听WeixinJSBridgeReady辅助恢复已被用户启用的声音，不绕过用户静音选择。
- 音频上下文恢复有超时；完整BGM无法载入时回退到原有程序配乐。声音许可失败不阻塞创建角色、教程与文字游玩；切到后台暂停，回来后恢复，必要时再次点按启用。
- 中文播音依赖浏览器／系统是否提供语音；不可用时继续保留插图、文字和音乐。
- 使用原生dialog，旧内核缺少showModal时回退到遮罩弹窗。支持滚动锁定、嵌套年报／喜报、焦点与Escape关闭；关闭后恢复原滚动位置。
- 为JSON存档补齐structuredClone、Object.hasOwn和queueMicrotask兼容实现。不支持ES模块和现代JavaScript语法的过旧内核仍需更新客户端。
- 微信与手机点击导出／导入会提供完整JSON文本入口，也保留文件操作。可复制、长按和粘贴；无剪贴板权限时提示手动复制。不向外部服务上传存档。存档键与数据格式延续第五版，旧进度自动继续。

## Vercel

仓库根目录新增 `vercel.json`：Other静态框架、`dist`输出、`npm test`构建校验、无需安装依赖。所有入口使用相对资源路径，兼容Vercel根路径与GitHub Pages子路径；HTML和脚本版本号一起更新以避免混用缓存。

推荐Vercel Root Directory为仓库根目录。若用户此前将Root Directory直接设为dist，静态文件也可从该目录提供，但根目录配置与测试命令不会生效。该项目无需Node服务器或server.mjs作为生产入口。

Vercel域名的网络可达性、微信对域名的安全判定与页面代码是不同问题：CSS／JavaScript无法修复域名被网络阻断或微信拦截。发布成功也不代表所有地区、运营商、客户端都能连接。生产域名如有这种问题，应在Vercel绑定手机和微信可正常访问的自定义域名并核对HTTPS与DNS。

## 验证与边界

- 46项自动测试：原有37项全部保留，新增原生／兼容弹窗、嵌套滚动恢复、教程弹窗重用、兼容API、微信音频用户意图、音频许可超时与Vercel输出配置测试。
- 浏览器验证：390px手机操作区与点击尺寸、文本存档往返；320px年报滚动与关闭后继续下一年；844×390横屏升迁插图和年报；1280pxPC三栏、隐藏手机导航、Escape释放滚动锁定；无控制台脚本错误。
- 当前环境没有Android／iPhone微信真机。上述为浏览器尺寸和兼容逻辑测试，不能冒充真机验收。测试网络访问用户的Vercel域名出现超时，需要结合部署状态与用户实际网络继续判断。
- 外部开放BGM与真实雷声仍受音源网络可达性影响；背景有备用配乐，无法载入的雷声会提示。游戏核心状态、题库、姓名、单位、头像与插图均由同站点静态文件提供。
