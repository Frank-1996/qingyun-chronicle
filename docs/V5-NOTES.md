# 第五版 · 观史明志，仙途延年

版本：0.5.0。继续使用公开 GitHub Pages 地址。

## 姓名

`names-data.js` 为随站点发布的实际姓名库，含 25,056 个不重复姓名：1,600 个两字姓名、20,000 个三字姓名、3,456 个复姓名字。随机抽取权重为普通两字25%、普通三字73%、复姓2%；复姓人物包含三字或四字姓名。随机角色、亲属、候选伴侣、单位负责人和相识官员共用该库。后代按完整姓氏继承，识别欧阳、司马、上官、诸葛、夏侯、东方、皇甫、慕容。

同一家族中的姓名持续去重，固定姓氏分支另有扩展名字与自然姓名回退，不追加数字后缀。已存在的旧存档姓名保留。

## 插图下的年度回顾

升年级、毕业、入学、入职与升迁播报的插图下，列出上一年五维净变化、寿命变化、重要里程碑、亲属健康与家庭变化及年度抉择。入学选择后的变化同步补入当年档案。回顾等待玩家点击“读完了 · 继续播报”，不随音效结束而消失。年度决策结果和人生档案也可回看。

旧存档迁移后的第一个不完整年度不虚构五维净变化；从下一个完整年度开始记录。年度回顾使用独立快照，后续选择不会改写已经排队的旧播报。

## 仙值与延寿

- 五维均大于100时觉醒；维持五维破百365天获得一次年度奖励。
- 任意维度大于等于1000时，永久解锁仙途进阶，此后的觉醒及年度奖励由1点变为10点，不叠乘、不追溯放大已有余额。即使属性后来下降，进阶仍保留。
- 进阶后可消耗1点仙值兑换1岁寿命，每次点击兑换1岁，上限150岁。1点抹去一次决策失误的功能保留。
- 进阶不会绕过“五维破百”的觉醒与年度获取条件。没有仙值时不能兑换。延寿不能复活，不能消除疾病，也不改变退休年龄。
- 创建角色的初始预期寿命仍为70–110岁，最多通过兑换延长至150岁。支持150次年度决策与保存／导入。

## 历史题库

实际发布128道独立情境题，来自8个历史节点，各有16种人生阶段／任职层级改写：婴幼儿、幼儿园、小学、初中、高中、本科、硕士、博士、社会实践、科员、乡镇、县域、城市、省域、国家、退休。

幼年由照护者陪伴选择；学生处理学习、实验与校园协作；官员题目按权限和治理范围改写；退休阶段侧重记录、照护与传承。同一类8题在本轮用尽前不重复，之后可再次抽取。选项顺序随角色与年龄变化，正确性来自人工编写的语义答案。

这128题是8个历史节点的不同情境改编，并非128件独立历史事件；游戏选择不等同于对复杂历史的唯一解释。作答后展示原事件、事实摘要、改编思路与一手机构来源：

## 教程与兼容

进入新角色或首次载入第五版时显示4步简短教程，包含一次无数值影响的选择练习。可跳过；在“玩法与设定”中可重看。完成／跳过后本角色不再自动弹出。新存档键为 `qingyun-save-v5`，兼容v1–v4并保留原键。

37项自动测试通过，覆盖姓名库及去重、历史题与不重复抽题、1000门槛与十倍奖励、兑换边界、150岁完整人生、年度回顾、旧存档。浏览器验证教程练习、旧存档迁移、插图下回顾、历史解析，以及149岁→150岁时扣除1仙值且兑换按钮禁用。

## 扩展入口

`history-data.js` 中的来源与题目独立于引擎，可新增历史节点或阶段题。`names-data.js` 与抽样逻辑独立；`annualReview`、`exchangeLifespan` 为独立引擎接口，后续可加入不同回顾主题与仙值用途。保留现有音乐、家族、单位与职级机制。
